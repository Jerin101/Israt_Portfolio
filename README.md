# 🔔 Israt Jerin Nafisa | Portfolio

A Doraemon-inspired personal portfolio website, built with plain HTML, CSS and JavaScript and hosted on GitHub Pages.

🌐 **Live site:** https://jerin101.github.io/Israt_Portfolio/

---

## 👩‍💻 About

I'm a 4th year Software Engineering student at Daffodil International University, majoring in Data Science. I enjoy turning data into insights and building practical applications.

## ✨ Features

- 🎨 Doraemon-inspired theme (blue, red collar, golden bell, cloud sky)
- 🌙 Day / Night mode toggle
- 🔔 Clickable bell with animation
- ⌨️ Typing text effect in the hero section
- 📊 Animated skill bars and counters
- 🗂️ Project filter (All / Data / Web / AI)
- 🃏 3D tilt effect on cards
- 🎓 Certificates section with verification links
- 📋 One-click "Copy email" button
- 📱 Fully responsive design

## 🛠️ Built With

- HTML5
- CSS3 (animations, grid, flexbox, CSS variables)
- Vanilla JavaScript
- GitHub Pages (hosting)
